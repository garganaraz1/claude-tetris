## Comandos mas comunoes en claude
Los comandos (slash commands) más usados en Claude Code son:

**Gestión de sesión**
- `/clear` — limpia el contexto de la conversación
- `/compact` — resume la conversación para liberar contexto
- `/resume` — retoma una sesión anterior
- `/cost` — muestra el consumo de tokens/costo

**Configuración**
- `/config` — ajustes generales (tema, modelo, etc.)
- `/model` — cambia el modelo activo
- `/permissions` — maneja permisos de herramientas
- `/memory` — edita el archivo de memoria/CLAUDE.md
- `/statusline` — configura la barra de estado

**Git / código**
- `/init` — genera un CLAUDE.md inicial para el repo
- `/review` — pide una revisión de código
- `/pr_comments` — trae comentarios de un PR

**Otros útiles**
- `/help` — ayuda general
- `/doctor` — diagnostica problemas de instalación
- `/agents` — lista/gestiona subagentes
- `/mcp` — gestiona servidores MCP conectados
- `/bug` — reporta un bug a Anthropic
